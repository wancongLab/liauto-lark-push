# 真实飞书截屏（放这里）

这个目录放**你自己手机上截的真图**，和 `screenshots/cards/` 里的复刻渲染图分开：

| 目录 | 是什么 |
|---|---|
| `screenshots/cards/` | 用真实卡片 JSON 渲染的复刻图（可复现，`tools/card_render.py`） |
| `screenshots/real/` | 手机真实截屏（飞书聊天窗口、面板、分享页），证明「真的在跑」 |

**命名建议**（README 里会按这个顺序展示）：

```
01-feishu-chat.png      飞书聊天里连续几张推送卡
02-feishu-buttons.png   卡片按钮点完的状态（或 toast）
03-panel-mobile.png     手机浏览器里的面板首屏
04-share-trip.png       行程分享页（有线路图那页）
05-*.png                其他你喜欢的角度
```

- 原图直接放，不用压缩（iPhone 的 HEIC 也能放，我会转成 PNG）。
- 截图里如果出现车牌、住址、还显示精确到米的坐标，请告诉我，我会打码后替换。
